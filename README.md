# my dotfiles

1. install brew
https://brew.sh/
2. install git
```
brew install git
```
3. install dotfiles
```
cd ~/
git clone git@github.com:sairoutine/dotfiles.git
```
4. exec dotfilesLink.sh
```
cd ~/dotfiles/
sudo ./dotfilesLink.sh
```
5. install following applications
```
hyper.js
zsh
nvim
tmux
```
6. setup vim
